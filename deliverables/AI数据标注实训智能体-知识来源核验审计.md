# AI 数据标注实训智能体 · 知识来源核验审计（只读）

审计日期：2026-09-11

## 结论摘要

当前文档已主动把两个来源标为“候选来源”，并对 COCO 字段边界作了保守说明，这是正确方向。正式提交前仍应附教师复核记录、实际版本文件和条款/页码；不得把候选来源写成已核验的国家标准依据。

## 可核验的来源信息

### 1. 数据标注职业技能等级标准

可核验版本的封面信息为：

- 标题：**《数据标注职业技能等级标准（2021 年 1.0 版）》**（标题不含“员”字）。
- 制定单位：**哈工大大数据集团有限公司**。
- 发布信息：**2021 年 3 月发布**。
- 前言第 1 页/正文页码（PDF 页 4）说明：该标准用于数据标注职业技能培训、考核与评价；属于职业技能等级标准，不是人社部颁布的《国家职业技能标准》。
- 与本项目最直接的条目：正文 PDF 页 8，初级图像标注 2.2.1，要求按指南使用平台完成图像 2D 拉框，合格率不低于 90%；PDF 页 11，中级图像标注 2.2.1，要求 2D 拉框和图片分类准确率在 95% 以上；PDF 页 11，2.3.1 涉及标注任务质检/审核。

建议正式引用写成：

> 哈工大大数据集团有限公司，《数据标注职业技能等级标准（2021 年 1.0 版）》，2021 年 3 月发布，图像标注 2.2.1/2.3.1（以团队保存的版本页码为准）。

不要写成“《数据标注员》职业技能等级标准（2021）”；该写法无法对应上述封面，且容易与国家职业标准混淆。该标准的知识产权声明还要求使用/复制遵守权利人许可，提交材料应使用脱敏摘录或仅列条款，不要无授权上传整本 PDF。

### 2. 人工智能训练师国家职业技能标准

可核验版本封面和说明信息为：

- 标题：**《人工智能训练师国家职业技能标准（2021 年版）》**。
- 职业编码：**4-04-05-05**。
- 制定/颁布部门：**中华人民共和国人力资源和社会保障部、中华人民共和国工业和信息化部**。
- 公布文件：**人社厅发〔2021〕81 号**，说明页注释为 2021 年 10 月 21 日公布。
- 标准第 1.3 节说明本职业包含“数据标注员”和“人工智能算法测试员”两个工种。
- 最直接的内容位置：标准正文 PDF 页 10（印刷页 6），五级/初级工“数据标注”要求按规范完成视觉数据清洗和标注；PDF 页 12（印刷页 8），四级/中级工“数据标注”要求完成标注数据准确性、完整性审核并纠错。

建议正式引用写成：

> 人力资源和社会保障部、工业和信息化部，《人工智能训练师国家职业技能标准（2021 年版）》（职业编码 4-04-05-05），人社厅发〔2021〕81 号，相关条目：3.1/3.2“数据标注”（页码以团队保存版本为准）。

不要把“人工智能训练师”写成仅针对数据标注的标准，也不要用新闻报道替代标准原文。新闻报道只能作为发布事实的旁证，不能证明具体字段规则（如 `occluded`/`truncated`）。

### 3. Microsoft COCO Dataset format

官方页面：<https://cocodataset.org/dataset/format-data.htm>；官方 API 仓库说明：<https://github.com/cocodataset/cocoapi>。

目标检测 annotation 结构明确列出：`id`、`image_id`、`category_id`、`segmentation`、`area`、`bbox`、`iscrowd`；页面说明 `bbox` 为从图像左上角计、0-indexed 的 `[x,y,width,height]`，`iscrowd=0/1` 用于实例/群体标注，且遮挡示例可用多个 polygon。官方格式**没有定义** `occluded` 或 `truncated` 字段。

建议页面和文档继续保留“COCO 仅作字段/坐标参考；平台属性以学校 schema 或教师核验实训手册为准”的措辞。不能把 COCO 作为国家/行业标准，也不能据此断言学校平台必须填写 `occluded`/`truncated`。

## 对当前项目文档的修订建议

1. 将“《数据标注员》职业技能等级标准（2021）”统一改为“《数据标注职业技能等级标准（2021 年 1.0 版）》（哈工大大数据集团有限公司制定）”，并增加“职业技能等级标准，非国家职业标准”的限定。
2. 将“《人工智能训练师》国家职业技能标准（2021）”统一改为完整标题、职业编码和发文号；在证据矩阵中写明对应条款/页码，而不是只写“实例区分与一致性”。
3. 对“遮挡沿可见轮廓”“截断框不越界”等规则，标注为“候选实训规则/平台 schema 待教师复核”，除非教师能提供本校手册的明确条款；不要声称这些字段规则直接来自 COCO 或上述国家标准。
4. 在提交包中保存每个来源的版本文件、封面、相关条款截图/页码和教师复核表；来源 URL 作为辅助，不替代文件版本。
5. 反馈与模拟记录中的评分只能作为演示，不能当作来源核验或真实用户证据。

## 当前风险等级

- 数据标注职业技能等级标准名称/性质：**中风险，已可纠正**。
- 人工智能训练师国家标准：**低风险，补齐编码、发文号和条款页码即可**。
- COCO 字段边界：**低风险，当前项目的保守说明正确**。
- 本校平台字段和场景真实性：**高风险，必须由真实教师/实训材料补证**。
