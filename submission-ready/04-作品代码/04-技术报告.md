# 04 BiliLearn 岗学智练技术报告

## 系统目标

BiliLearn 岗学智练服务于软件技术专业学生在综合实训、技能竞赛和岗位实习准备阶段的个性化学习。系统围绕软件开发工程师岗位建立统一的能力维度、知识目录、诊断结果和任务记录，使学习者能够从岗位目标出发完成诊断、学习和复测闭环。

## 总体架构

系统采用前后端分离与多服务架构：

- `a3-student-react-web` 提供岗位学习、诊断、知识目录、路径、资源和学习效果页面。
- `a3-admin-web` 提供运营与内容管理入口。
- Java 服务承担网关、用户、课程、学习记录、测评和稳定业务流程。
- `a3-ai-python` 承担岗位知识检索、学习规划、智能辅导、评估与星辰 Agent 集成。
- MySQL、PostgreSQL、Redis、MinIO 和 Milvus 分别承载业务数据、AI 结构化数据、缓存、对象存储和向量检索。

## 岗位能力模型

系统固定五个能力维度：需求理解与分析、系统设计、编码实现、软件测试、项目协作与交付。前端类型、Python 接口和岗位知识目录使用统一标识，避免诊断结果、知识条目和路径任务出现口径漂移。

## 岗位知识目录

知识目录包含 K001 至 K080 共 80 条。每条包含知识点、技能点、适用场景、常见错误、学习建议、安全提示和来源，并可生成任务提示、提交产出、验收标准与建议用时。离线测试检查条目数量、唯一性、五维覆盖、来源字段和技能点完整性。

目录文件：

`a3-ai-python/xfyun_agent/knowledge/software-job-ability-knowledge-catalog.md`

## 智能体逻辑

星辰 Agent 接收学习目标和当前问题。信息不足时先澄清，再获取诊断摘要和薄弱能力，检索带来源的岗位知识，输出分步骤建议、安全提示和下一步任务。知识未命中时降低确定性并说明限制，禁止编造教材页码、标准编号或文献。

## 学习闭环

1. 学生选择课程达标、综合实训、技能竞赛或岗位实习目标。
2. 学生完成五维岗位能力诊断。
3. 系统根据薄弱项、目标和可投入时间生成路径。
4. 学生查看带来源资源并完成可验收任务。
5. 系统记录提交与完成状态。
6. 学生复测后，系统更新学习效果和下一步建议。

没有第二次真实测评时，系统只显示基线状态，不生成能力提升结论。

## 工程验证

现有记录显示比赛关键后端目录与门户测试 25 项通过，学生端 TypeScript 检查和 Vite 构建通过，主分支 GitHub Actions 构建成功。具体命令、提交与证据边界见 `06-其他材料/06-自动化测试报告.md`。

## 数据与安全

- 不在源码、日志和提交包中保存模型密钥、令牌或真实个人敏感信息。
- 本地 SQLite 记录只用于开发演示。
- AI 生成内容必须显示明显标识。
- 知识未命中、高风险操作和重要结论要求人工复核。
- 第三方代码与素材按许可证或授权范围使用。

## 可复现性

源码包保留依赖清单、Docker Compose、本地启动脚本、数据库脚本、测试用例和 Kustomize 部署清单。复现人员应先阅读 `AI_START_HERE.md`，再按 `04-源码复现说明.md` 执行环境检查、安装、启动和最终服务验收。
