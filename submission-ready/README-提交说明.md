1. 在 `01-参赛信息` 放入报名系统审核通过的参赛报名表，逐字段核对系统信息。
2. 在 `02-作品 Demo/02-作品Demo说明.md` 填入当前有效的星辰 Agent 编号或体验地址，以及稳定的 Web Demo 地址。
