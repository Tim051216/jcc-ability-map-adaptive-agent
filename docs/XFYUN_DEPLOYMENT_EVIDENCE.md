## 可重复的入口连通性检查

运行 `powershell -ExecutionPolicy Bypass -File scripts/verify_xfyun_status.ps1` 可检查知识库和工作流入口是否返回 HTTP 200，并写入 `docs/xfyun-status-check.json`。该脚本不携带账号、不读取个人信息，也不会把 HTTP 200 误判为平台发布状态。
