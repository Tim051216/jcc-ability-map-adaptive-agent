# 教学进度与章节安排

以下安排依据教学进度表、教案文件名和 PPT 章节名称整理，适合作为课程问答和学习计划的基础章节框架。

## 周次主线

- 第1周：第1章 软件工程基础
- 第2-3周：第2章 可行性分析及研发策划
- 第4-5周：第3章 软件需求分析
- 第6周：第4章 软件设计
- 第7-8周：第5章 面向对象开发方法
- 第8-9周：第6章 软件编程实现
- 第10-11周：第7章 软件测试调试与维护
- 第12周：第8章 软件项目管理
- 第13周：第9章 软件工程新技术及体系
- 第14周：第10章 WebApp 开发综合应用

## 实验与实践穿插点

- 可行性分析及报告编写
- 软件需求分析及文档
- 面向对象分析与设计训练
- 软件实现规范与编码训练
- 测试、调试、维护相关练习
- WebApp 综合开发实践

## 典型教学组织方式

- 课前发放预习任务
- 课中讲授重点、难点、知识点与案例
- 课后布置作业、实验准备、讨论交流
- 通过课程群、在线平台、视频与电子书支撑混合教学
