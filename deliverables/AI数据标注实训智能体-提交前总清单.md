## 验收命令

```powershell
Set-Location .\a3-student-react-web
npm run lint
npm run build
npm run smoke:ai-annotation-agent
npm run audit:ai-annotation-deliverables
npm run audit:ai-annotation-submission
```

上述开发命令的绿色结果只能证明代码、构建、浏览器回归和提交材料自检通过；不得把它们写成真实用户测试结论。

提交预检还会单独提示三类容易遗漏的正式材料：报名表 PDF、可持续访问的 HTTPS Demo/星辰 Agent 地址，以及负责人签署的安全与合规承诺 PDF。它们与场景、教师复核和真人反馈一样，必须由团队据实补入；本地地址、模板和 AI 模拟录屏不能替代。

提交门禁（真人材料补齐后执行）：

```powershell
npm run audit:ai-annotation-submission -- --strict
```

`--strict` 在真实场景记录、教师复核、真实用户反馈或外部证据人工核验声明未完成时会退出 1；这是预期的保护。它不能判断签名真伪或参与者身份，不能通过改名或手工编辑记录绕过。
