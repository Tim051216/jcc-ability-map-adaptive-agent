# A3 Student React Web

`a3-student-react-web` 是当前仓库默认学生端前端，面向 A3 个性化学习场景，聚合学习总览、能力画像、学习路径、资源中心、学习报告、学习测评和 AI 辅导等核心链路。

## Local Run

前置条件：`Node.js 18+`

1. 安装依赖：`npm install`
2. 如需覆盖 AI 服务地址，可在环境文件中设置 `VITE_AI_BASE_URL`
3. 启动开发环境：`npm run dev`

默认开发地址：`http://localhost:3002`

## Scripts

- `npm run dev`：启动本地开发服务
- `npm run build`：构建生产产物
- `npm run lint`：执行 TypeScript 类型检查
