# 04 源码复现说明

## 交付内容

本目录包含 `04-BiliLearn作品代码.zip`。源码包覆盖学生端、管理端、Java 业务服务、Python AI 中台、数据库脚本、部署清单、测试与说明文档。模型文件未直接打包；模型与星辰 Agent 采用外部服务配置方式，具体配置项见源码中的示例环境文件和 `a3-ai-python/xfyun_agent/README.md`。

源码包不包含真实密钥、访问令牌、`.env`、运行日志、本地数据库、上传文件、依赖缓存、构建产物或临时目录。

为控制邮件附件体积，源码包还排除了学生端 `public/videos` 下的演示视频和 `public/models` 下的大型三维模型文件。这些内容属于可选演示媒体，不是岗位学习接口、知识目录、诊断、路径和测试闭环的必需代码。团队如需复现完整媒体页面，应从团队原始资产库恢复对应文件，并重新核对素材授权。

## 推荐环境

- Windows 10 或 Windows 11
- Docker Desktop
- JDK 17
- Node.js 20
- Python 3.12
- Git

## Windows 复现步骤

在解压后的源码根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\doctor-local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-full-local.ps1 -NoOpenPages
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\doctor-local.ps1 -RequireServices
```

最终 `doctor-local.ps1 -RequireServices` 返回退出码 0，视为本地完整服务启动通过。不要为通过检查而覆盖已有 `.env`、重置数据库或删除 Docker 数据卷。
