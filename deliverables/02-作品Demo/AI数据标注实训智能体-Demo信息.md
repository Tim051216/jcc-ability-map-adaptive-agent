# AI 数据标注实训智能体 Demo 信息

## Demo 定位

- 专业群：人工智能技术应用专业群（计算机视觉方向）
- 核心岗位：AI 数据标注工程师
- 微任务：处理目标检测标注中的遮挡、截断和同类实例粘连判定
- 输入：文字描述
- 输出：规则命中、分步骤框选建议、框选示意、属性提醒、常见错误、来源依据和反馈评分

## 地址与启动

本机启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-ai-annotation.ps1
```

脚本会在首次运行时按锁文件安装依赖，并自动打开主页面；在终端按 `Ctrl+C` 停止。若不希望自动打开浏览器，可加 `-NoOpen`。

- 本机地址：<http://127.0.0.1:3002/annotation-agent>
- 兼容地址：<http://127.0.0.1:3002/ai-annotation-agent>
- 局域网地址：`http://<项目电脑 WLAN IPv4>:3002/annotation-agent`

`127.0.0.1` 和 `localhost` 只用于本地验收，不是正式的公网演示地址。正式提交时请替换为团队可持续访问的 HTTPS 地址或主办方要求的星辰 Agent 体验地址。

## 三分钟演示脚本

1. 打开 `/annotation-agent`，先指出顶部的专业群、岗位和“候选场景 / 待来源核验”状态。
2. 点击快捷问题“这张图里的人被车挡住了，框怎么画？”，说明系统命中遮挡规则，返回步骤、错误提示和候选依据。
3. 输入“这个怎么弄？”，展示系统不会猜测，而是追问遮挡、截断、同类实例和任务类型。
4. 输入“目标检测，目标出画面了”，展示截断规则和 `bbox` 检查，并说明 `truncated` 字段以学校平台 schema 为准。
5. 输入“同类目标挨在一起，应该标几个框？”，展示按独立实例分别标框的质检提示。
6. 输入“人被车挡住并且目标出画面，怎么标？”，展示多意图先澄清，避免直接套用错误规则。
7. 指向右侧“框选示意”图，说明绿色框只覆盖可见目标、蓝色框贴合图像边缘；图下注明“示意图（非真实样本）”。
8. 打开“提交试用反馈”。没有真人参与时选择“AI 模拟（内部演示）”；只有参与者本人完成试用时才选择“真实用户试用”，并由本人勾选匿名确认。

## 演示讲解重点

- 输入到反馈在一个页面内完成，不要求评委跳转外部工具。
- 页面顶部、场景卡和助手回答显示“AI生成内容 · 教学辅助”，演示时说明候选规则必须经过教师核验。
- 页面规则库使用稳定 ID，并在每条回答中显示来源边界。
- 每条命中结果显示规则 ID、来源编号、定位和候选/已核验状态，便于教师复核。
- 模糊问题触发澄清，符合 2-3 轮基础对话管理要求。
- `occluded`、`truncated` 不是由 COCO 页面臆造的字段，必须以学校平台和教师核验记录为准。

## 异常与兜底

- 页面打不开：确认 3002 端口未被占用，重新运行启动脚本；若端口冲突，可使用 `-Port 3012`，并把下方地址中的端口同步改为 3012。
- 局域网设备打不开：确认项目电脑和试用设备在同一 Wi-Fi，并检查 Windows 防火墙入站规则。
- 反馈导出为空：先保存至少一条记录；按当前记录类型分别导出。
- AI 模拟记录：只能作为内部演示和回归材料，不能放入第 8 项真实证据位。
