# AI 数据标注实训智能体 · 试用与演示指南

## 1. 启动前端

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-ai-annotation.ps1
```

或手动运行：

```powershell
Set-Location .\a3-student-react-web
npm install
npm run dev -- --host 0.0.0.0 --port 3002
```

浏览器打开：

- 本机：<http://127.0.0.1:3002/annotation-agent>
- 兼容地址：<http://127.0.0.1:3002/ai-annotation-agent>
- 同一 Wi‑Fi 的其他设备：`http://<本机 WLAN IPv4>:3002/annotation-agent`（用 `ipconfig` 查询 IPv4）

页面只依赖前端规则库，演示该 MVP 不需要启动大模型、数据库或向量库。页面右侧默认展示 3 条核心执行规则，并可展开 K001–K060 共 60 条候选知识条目；条目均标记“待教师核验”。若局域网设备无法访问，先检查 Windows 防火墙的入站规则；不要为了演示关闭整机防火墙。

## 2. 三分钟技术演示脚本

1. 点击快捷问题“这张图里的人被车挡住了，框怎么画？”。确认出现遮挡判定、4 个步骤、常见错误和“依据”。
2. 输入“这个怎么弄？”。确认智能体先追问遮挡、截断、同类粘连及任务类型。
3. 继续输入“目标检测，目标出画面了”。确认出现截断规则、边界和 `bbox` 检查，并看到 COCO 字段边界说明。
4. 点击“同类目标挨在一起，应该标几个框？”。确认回答“按独立实例分别标框”，而不是合并大框。
5. 打开“提交试用反馈”。内部演示请选择“AI 模拟（内部演示）”；真实参与者到场后才选择“真实用户试用”。
6. 在反馈窗口勾选与记录类型对应的匿名确认后保存。保存三条记录后点击“导出当前类型记录”。页面只导出当前选择的类型：模拟记录生成带 `AI模拟` 的文件名；真实用户记录生成 `AI数据标注真实用户反馈.csv`，并附“匿名记录确认/确认时间”列。

## 3. 真人试用脚本

真实参与者应由项目成员现场分配匿名身份 A/B/C，并在不观看开发者讲解的情况下完成第 2 节前四个输入场景。参与者本人填写评分和意见并勾选匿名确认，项目成员只负责导出 CSV 与保存经同意的匿名证据。详细记录见 `AI数据标注实训智能体-真实试用执行清单.md`。

## 4. AI 角色模拟边界

如果暂时找不到学生或教师，可以用 AI 角色模拟检查对话流程，但必须：

- 在记录类型中选择“AI 模拟（内部演示）”；
- 在文档和 CSV 中保留“AI 模拟”字样；
- 不填写虚构姓名、学校、日期、访谈原话或视频链接；
- 不把模拟评分写入第 8 项“真实用户测试”栏。

AI 模拟的目的仅是发现交互问题、准备现场脚本和验证导出格式。
