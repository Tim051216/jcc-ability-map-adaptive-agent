# AI 数据标注实训智能体 · 岗位适配说明

## 适配目标

本 MVP 当前服务“人工智能技术应用专业群（计算机视觉方向）—AI 数据标注工程师”岗位。输入、追问、步骤化反馈、匿名试用记录和 CSV 导出被设计为稳定接口，专业差异集中在规则与知识条目层。

## 适配步骤

1. **替换知识条目**：在 `src/data/aiAnnotationKnowledge.ts` 中替换标题、内容、触发词、来源编号和定位；每条内容保留 `candidate` 状态，直到目标课程教师核验。
2. **替换字段规则**：根据目标平台 schema 更新 `src/data/aiAnnotationRules.ts` 的输出提示和字段检查，不把 COCO 或通用教材直接当作本校字段规范。
3. **增加核心意图**：为新微任务增加稳定 ID、关键词和一个确定性回答分支，同时补 3 个正例与 2 个模糊提问 smoke 用例。
4. **补齐来源证据**：为每条条目记录课程标准、实训手册或行业规范的版本、条款/页码和授权边界；由教师填写核验记录后再把状态改为 `verified`。
5. **重新回归**：运行 `npm run lint`、`npm run build`、`npm run smoke:ai-annotation-agent` 和 `npm run audit:ai-annotation-deliverables`，并重新生成预提交包。

## 可适配范围

- 计算机视觉：目标检测框选、实例分割、关键点和图像质检；
- 语音数据：语音切分、说话人区段和转写质检；
- 文本数据：文本分类、实体标注和一致性复核。

跨岗位适配时，必须重新确认术语、字段、阈值、数据授权和安全边界。该工具是教学与岗位入门辅助，不用于未经专家复核的生产质量判定、医疗/安全关键决策或自动处罚。

## 当前状态

本文件说明的是可复用方法，不代表已经完成其他专业的真实部署。当前 AI 版仍需真实场景来源、教师核验、真人试用、正式 Demo 地址和签署版合规材料。
