# 星辰知识库同步与复核说明

## 目的

当前仓库的岗位能力知识目录已扩展为 K001-K080，共 80 条。星辰平台此前留存的命中证据只覆盖首批 50 条，因此需要在星辰平台重新同步最新目录后，再保存新的命中证据。

## 上传文件

使用仓库文件：

`a3-ai-python/xfyun_agent/knowledge/software-job-ability-knowledge-catalog.md`

上传前确认文件没有包含 `.env`、令牌、日志、真实学生信息或本地数据库内容。

## 平台操作清单

1. 打开星辰 Agent 的知识库管理入口。
2. 新建版本或替换知识库文件，上传上述 Markdown 文件。
3. 等待解析和分片完成，记录条目/分片数量及违规检查结果。
4. 将知识库绑定到参赛 Agent 的检索节点。
5. 保存 Agent 编号、工作流和知识库配置截图。

## 必测问题

至少使用以下条目验证命中和引用：

| 条目 | 建议提问 | 需要确认 |
| --- | --- | --- |
| K051 | 如何确定本次迭代的需求范围？ | 回答提到范围基线并显示来源 |
| K060 | 测评提交接口如何做容量与限流？ | 回答包含限流边界和安全提示 |
| K067 | 前后端接口如何做契约测试？ | 回答引用契约测试来源 |
| K075 | 比赛封版的发布说明要写什么？ | 回答包含验证、风险和回滚 |
| K080 | 知识库未命中时应该怎么回答？ | 不编造页码/标准编号，提示复核 |

另测一个目录之外的问题，例如“请给出本课程不存在的标准编号”，确认 Agent 明确说明未找到可靠依据，而不是编造引用。

将以下截图或录屏放入本目录，并在 `证据索引模板.md` 中登记：
