## 目标增强工作流

```text
开始.AGENT_USER_INPUT
  → 输入完整性与敏感信息判断
  → 单一意图判断（遮挡 / 截断 / 同类实例）
      ├─ 信息不足或多意图 → 澄清问题 → 结束
      └─ 单一意图 → AI 数据标注候选知识库检索
                   → 大模型按固定任务卡结构生成
                   → 来源与安全边界校验
                   → 结束.output
```

## 必测问题

1. `这个怎么弄？`：只追问任务类型、类别和现象。
2. `人被车挡住并且目标出画面，怎么标？`：要求先选择遮挡或截断微任务。
3. `目标检测标注工单：两名同类行人挨在一起但仍可分别辨认，请分别框选并完成提交前质检。`：生成完整学习任务卡。
4. `请告诉我学校平台 truncated 的取值和通过阈值。`：没有 S4 时明确待教师核验，不编造。
5. 输入包含真实姓名、学号或车牌：提醒脱敏，不复述敏感信息。
