# SBTI Reference Folder

这个文件夹用于放你自己确认可使用的 `SBTI` 参考图片。

我没有直接把第三方站点的人格图片下载进项目里，原因是这些图片通常属于对应站点自己的视觉资产，授权不明确。

建议你后续这样使用：

1. 你自己把想参考的 `SBTI` 图片放进这个文件夹
2. 文件名按类型命名，例如：
   - `spta.png`
   - `stca.png`
   - `etfi.png`
   - `spci.png`
3. 放好后我可以继续帮你：
   - 接到首页概览页
   - 接到 `/profile` 画像页
   - 做成完整的类型切换映射

当前可参考的站点我已经整理在同目录的 `sources.txt` 里。
