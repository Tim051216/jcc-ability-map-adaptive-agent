# 实验、课设与工具资源

课程配套资源不仅有理论资料，还包含实验、课设、建模、测试和移动应用案例，可用于资源推荐、课设选题和实践指导。

## 实验与课设方向

- 可行性分析实验
- 需求分析及文档编写
- UML 建模与流程图绘制
- 测试工具学习与测试实践
- WebApp 或移动应用综合开发

## 典型工具与资料

- Visio 培训教程
- Visio 流程图制作详解
- Rational Rose UML 建模教程
- 软件测试工具资料

## 案例资源特点

- 包含 Android 方向的课程设计题目、开题报告和案例论文
- 适合延伸为移动应用、信息系统、管理系统类课设题目
- 部分资料强调数据流图、系统功能结构图、模块划分和界面设计

## 适合系统怎么用

- 资源中心可推荐实验参考文档
- AI 助教可基于课设方向给出选题建议
- 学习路径可结合章节进度推荐对应实验
