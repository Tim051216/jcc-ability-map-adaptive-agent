# 06 封包前检查表

## 目录与格式

- [ ] 01 至 06 六个目录名称与比赛通知完全一致。
- [ ] 01 包含报名系统审核通过的参赛报名表。
- [ ] 02 包含当前有效的星辰 Agent 编号或 Demo 体验地址及说明。
- [ ] 03 包含 PPT，且文件小于 100MB。
- [ ] 04 包含源码、模型或服务说明、技术报告和复现说明。
- [ ] 05 包含负责人签字或校方盖章确认的 PDF。
- [ ] 06 的人工证据均为真实记录并已脱敏。

## 信息一致性

- [ ] 提报单位使用学校全称。
- [ ] 比赛题目、作品名称、负责人姓名和联系方式与报名系统一致。
- [ ] PPT、Demo 说明、合规声明和压缩包名称使用同一作品名称。
- [ ] 团队成员和指导教师信息与审核通过的报名表一致。

## 安全与知识产权

- [ ] 压缩包不含 `.env`、密钥、令牌、日志、本地数据库或真实个人敏感信息。
- [ ] AI 生成内容有明显标识。
- [ ] 不存在虚假文献、虚假学术数据或伪造试用记录。
- [ ] 开源代码、课程资料、图片、视频和字体已经核对来源和授权。

## 最外层压缩包

命名格式：

`提报单位全称－题目名称－作品名称－团队负责人姓名－团队负责人联系方式.zip`
