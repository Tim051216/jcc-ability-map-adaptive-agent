# RobotOps 工业机器人系统运维实训智能体

## 1. 场景真实性

- **专业群**：机电一体化技术（工业机器人方向）
- **典型岗位**：工业机器人系统运维员
- **谁、什么环节、什么困难**：机电专业学生在机器人回零、点动实训环节遇到 E-STOP 报警时，常跳过安全门与外部急停回路确认，直接反复 RESET，导致排查耗时且存在误动作风险。
- **场景来源**：依据校内工业机器人实训任务“安全回路复位与低速试运行”整理；正式提交时附 1 名实训教师访谈记录和 2 名学生试用记录，当前页面不虚构访谈结论。

## 2. 功能闭环

文本输入现象 → 检索 3 条结构化工业机器人运维知识 → 识别任务与风险 → 输出分步排查、低速验证、常见错误和关联微课 → 用户提交试用反馈。模糊问题会追问品牌/型号及当前环节，支持连续 2-3 轮对话。

## 3. 内容依据

1. GB/T 20867-2007《工业机器人 安全实施规范》：工作区进入、急停与安全回路要求。
2. 《工业机器人系统操作员》职业技能等级标准（2021）：报警识别、复位和试运行要求。
3. 《工业机器人技术基础》（机械工业出版社，2022）P78-81：工具/工件/世界坐标系切换。
4. ABB IRC5 操作手册 3.2：示教器点动与坐标选择（演示设备可替换为学校实际品牌）。

## 4. MVP 验证方式

启动 `a3-student-react-web` 后访问 `/robot-ops-agent`。可输入“回零后报警 E-STOP”或“示教器坐标系怎么切换？”，检查是否返回步骤、依据和安全提示；点击“提交试用反馈”记录学生/教师意见。
