# BiliLearn 项目总览

## 这是什么项目

BiliLearn 是一个面向学生端与管理端的个性化学习多智能体系统。项目不是单一聊天机器人，而是把“学习目标确认、学习画像、学习路径、资源生成、答疑支持、测评反馈、画像更新”串成闭环。

## 核心闭环顺序

当前推荐的学生学习闭环顺序是：

1. 学习目标选择或进入课程
2. 初始画像与状态识别
3. 学习规划
4. 资源生成
5. 答疑支持
6. 测评反馈
7. 画像更新

如果用户是新用户，系统不应该一上来假设已经存在稳定画像。更合理的逻辑是先由用户选择要学什么，再结合当前课程和行为生成初始画像。

## 项目包含哪些端

项目主要包含四部分：

- 学生端前端：`a3-student-react-web`
- 管理端前端：`a3-admin-web`
- Java 业务服务与网关：负责课程、测评、消息、网关转发等稳定业务链路
- Python AI 中台：`a3-ai-python`，负责 RAG、AI 导师、学习规划、资源生成、画像分析等能力

## 学生端主要页面

学生端默认开发地址是 `http://localhost:3002`，核心页面包括：

- `/`：概览页，展示今日学习驾驶舱、推荐学习视频、智能体闭环总览
- `/path`：学习路径页，展示阶段目标、任务顺序、下一步建议
- `/learn`：课程学习页，侧重边看边学和随堂陪学
- `/resources`：资源中心，查看已有资料与按类型补资料
- `/resources/preview`：资料预览页，打开文档、视频、图片等资料
- `/report`：阶段报告页，查看学习结果与下一步补强建议
- `/evaluation`：测评页，进行阶段测评或查看结果
- `/profile`：学习画像页，查看用户当前能力维度与 AI 导师协同信息
- `/im`：站内消息页，处理课程群、系统通知、私聊会话
- `/tutor`：AI 导师页，做直接问答、截图提问、生成笔记、讲义、脑图、练习等

## 管理端主要作用

管理端面向老师、助教或运营人员，主要负责：

- 查看平台概览和关键数据
- 触发知识库入库
- 检查 AI 服务状态
- 查看用户治理与站内通知
- 管理课程资料、智能体链路与教学运营

## AI 导师能做什么

AI 导师不只是普通问答窗口，它可以结合本地课程知识库和页面上下文完成：

- 解释课程概念
- 基于当前页面内容回答“我下一步该做什么”
- 基于截图、多模态或正文进行问答
- 帮用户生成笔记、讲义、脑图、练习
- 在本地知识库不足时，补充联网检索结果
