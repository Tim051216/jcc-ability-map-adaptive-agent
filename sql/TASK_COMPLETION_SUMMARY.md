## 技术特点

### 数据库设计亮点

1. **完整的路径管理体系**
   - 路径主表 → 节点表 → 资源表,层次清晰
   - 支持路径状态管理(草稿/激活/进行中/完成/暂停/废弃)
   - 支持路径类型(AI自动规划/教师指定/混合模式)

2. **灵活的数据结构**
   - 13个JSON字段支持复杂数据存储
   - 知识点列表、完成条件、调整数据等都使用JSON
   - 支持动态扩展,无需修改表结构

3. **细粒度的进度追踪**
   - 路径级别进度
   - 节点级别进度
   - 资源级别进度
   - 详细的进度记录表

4. **智能路径调整**
   - path_adjustment表记录所有调整
   - 支持自动优化和手动调整
   - 保存调整前后快照,可回溯

5. **完善的索引设计**
   - 主键索引
   - 外键字段索引
   - 状态字段索引
   - 时间字段索引
   - 唯一索引(learning_statistics)

6. **规范的时间管理**
   - create_time: 创建时间
   - update_time: 更新时间(自动更新)
   - 业务时间: activate_time, start_time, complete_time等
