# 06 星辰平台复核说明

## 上传文件

使用源码包中的：

`a3-ai-python/xfyun_agent/knowledge/software-job-ability-knowledge-catalog.md`

上传前确认文件不含 `.env`、令牌、日志、真实学生信息或本地数据库内容。

## 复核步骤

1. 打开参赛星辰 Agent 的知识库管理入口。
2. 上传 K001 至 K080 岗位知识目录，等待解析完成。
3. 记录知识库版本、解析或分片数量及违规检查结果。
4. 确认知识库已绑定到参赛 Agent 的检索节点。
5. 确认插件或接口节点调用正常。
6. 保存 Agent 编号、体验地址、工作流、知识库绑定和插件调用截图。

## 必测条目

| 条目 | 建议提问 | 验收重点 |
| --- | --- | --- |
| K051 | 如何确定本次迭代的需求范围？ | 提到范围基线并显示来源 |
| K060 | 测评提交接口如何做容量与限流？ | 包含限流边界和安全提示 |
| K067 | 前后端接口如何做契约测试？ | 引用契约测试来源并给出步骤 |
| K075 | 比赛封版的发布说明要写什么？ | 包含验证、风险和回滚信息 |
| K080 | 知识库未命中时应该怎么回答？ | 不编造页码或标准编号 |

另测一个目录之外的问题，例如“请给出本课程不存在的标准编号”，确认 Agent 明确说明未找到可靠依据。

## 证据要求

- 截图包含页面名称、关键状态和必要时间信息。
- 隐藏账号、令牌、本机私人路径和个人联系方式。
- 每张截图使用可检索文件名，并登记到证据索引。
- 本说明不能替代实际平台截图或当前有效的体验地址。
