# 06-补充材料

本目录只收集 AI 数据标注实训智能体的测试报告、截图、录屏、教师知识复核、真实用户试用反馈、星辰 Agent 配置证据和相近岗位适配说明。

人工智能数据标注版本的场景来源核验请使用上级目录的 `AI数据标注实训智能体-场景来源核验模板.md`；真实试用请使用 `AI数据标注实训智能体-真实试用执行清单.md`。来源、规则和页面输出的关系见上级目录 `AI数据标注实训智能体-来源规则输出映射.md`，60 条候选知识条目明细见上级目录 `AI数据标注实训智能体-知识库目录.md`，标准文件与页码核验见上级目录 `AI数据标注实训智能体-来源文件核验清单.md`，只读来源边界审阅见上级目录 `AI数据标注实训智能体-知识来源核验审计.md`，提交前总清单见上级目录 `AI数据标注实训智能体-提交前总清单.md`。模板未填写前不得把场景或反馈写成已核验事实。

前端提交预检命令为 `npm run audit:ai-annotation-submission`；真人材料齐备后可加 `-- --strict` 做严格门禁。预检只检查文件存在性、CSV 形态和声明文本，不替代参与者身份、授权、标准文件许可、教师专业判断或负责人签字的人工核验。

`AI数据标注实训智能体-AI模拟反馈.csv` 仅是 AI 角色模拟的演示数据；正式第 8 项证据必须使用页面选择“真实用户试用”后导出的 `AI数据标注真实用户反馈.csv`，并附匿名书面反馈、访谈纪要或经同意的视频。

技术演示录屏统一放在 `../02-作品Demo/演示录屏/`，文件名保留“AI模拟-内部演示”标识；它只用于展示前端闭环，不计入真人反馈证据。

《AI数据标注实训智能体-知识来源核验审计.md》位于上级 `deliverables/` 目录，属于只读来源边界审计，不替代教师复核、实际持有版本或授权确认。外部证据人工核验声明和安全合规承诺也只能在负责人/指导教师真实核对、签署后作为正式证据。

提交前还需处理 `AI数据标注实训智能体-外部证据人工核验声明模板.md` 和 `../05-安全与合规/AI数据标注实训智能体-安全合规承诺模板.md`：模板只能作为待办清单；完成后应将实际核验结果和负责人签署版按主办方要求归档，并在索引中更新状态。

材料边界：历史专业或其他岗位的说明、演示和反馈文件不纳入 AI 预提交包；不得用其替代人工智能专业群场景、教师核验或真人试用证据。
