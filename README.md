# A3 个性化学习多智能体系统

## 项目定位

本项目面向第十五届中国软件杯 A3 赛题《基于大模型的个性化资源生成与学习多智能体系统开发》进行重构与扩展。

当前仓库以在线学习微服务架构为基础，正在逐步演进为面向高校学习场景的多智能体系统，重点围绕以下能力建设：

- 对话式学生画像构建
- 多智能体协同生成学习资源
- 个性化学习路径规划与资源推送
- 学习过程跟踪与效果评估

## 当前改造原则

- 先完成项目对外标识、文档与服务说明的赛题化改造
- 保留现有稳定的模块结构，避免一次性大范围重命名影响可运行性
- 在此基础上逐步补齐学生画像、资源生成、学习路径、多模态内容等核心赛题能力

## 目录说明

- `tj-gateway`：网关服务
- `tj-auth`：认证与权限服务
- `tj-user`：用户中心服务
- `tj-course`：课程与资源服务
- `tj-learning`：学习过程服务
- `tj-exam`：题库与测评服务
- `tj-media`：媒资服务
- `tj-search`：检索与推荐服务
- `tj-data`：数据分析服务
