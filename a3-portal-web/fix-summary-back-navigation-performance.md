# 返回慢与首页体验修复总结

## problem
- 从 A3 学习页面返回首页时体感偏慢，首页还夹杂部分乱码文案，影响验收展示。
- 分类悬浮层和轮播区存在旧项目遗留文案，出现“右侧像空白”的观感问题。

## root cause
- 首页首屏依赖的课程分类、课程列表和 AI 页面数据在进入或返回时会触发额外请求，阻塞可见内容展示。
- 部分首页组件仍保留历史乱码字符串，且分类悬浮层没有空态兜底。

## changes
- 将 AI 页面拆分为快慢两类请求：读取最新结果走短超时，生成类接口保留长超时。
- 首页优先读取缓存并先渲染，再把分类、课程列表和兴趣数据放到空闲阶段静默刷新。
- A3 学习画像、学习路径、学习报告等页面改为“先展示已有内容，再后台刷新”。
- 重写首页主文案、轮播文案、课程分区标题和分类悬浮层文案，统一为 A3 赛题化中文表达。
- 为分类悬浮层补了空态提示，避免接口数据不完整时出现纯空白区域。

## verification

- 在本地浏览器重新加载 `http://127.0.0.1:18082/#/main/index` 后，首页主展示区已恢复为正常中文文案。
