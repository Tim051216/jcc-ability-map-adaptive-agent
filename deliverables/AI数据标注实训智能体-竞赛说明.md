# AI 数据标注实训智能体（人工智能专业版）

## 场景与岗位

- **专业群**：人工智能技术应用（计算机视觉方向）
- **典型岗位**：AI 数据标注工程师
- **谁、什么环节、什么困难**：人工智能专业学生在目标检测标注实训中，对遮挡、截断和同类目标粘连的框选规则理解不一致，导致质检返工和标注一致性评分低。
- **场景来源（候选，待核验）**：根据校内计算机视觉数据标注任务整理形成候选描述；正式提交前必须附真实课程/实训观察或标注教师访谈记录，不把候选描述写成已确认事实。

## 微任务闭环

输入图片现象或文字描述 → 在“3 条核心执行规则 + 60 条候选知识条目”的知识库中按意图匹配 1 条相关规则 → 识别遮挡/截断/实例粘连 → 生成框选步骤、属性字段和常见错误 → 显示来源并采集试用反馈。页面同时提供明确标注为“示意图（非真实样本）”的框选示意，帮助学生把文字规则对应到边界。输入“这张图怎么弄？”会先追问问题类型和任务类型，支持连续 2-3 轮对话。

其中 3 条核心执行规则负责当前微任务的确定性分支；60 条候选知识条目覆盖任务理解、bbox、遮挡、截断、实例拆分、质检、导出与合规等主题。每条条目都有来源编号、定位和 `candidate/待教师核验` 状态，知识条目数量不等于已核验标准条款数量。

## 知识来源

1. **S1：《数据标注职业技能等级标准（2021 年 1.0 版）》**（哈工大大数据集团有限公司制定，2021 年 3 月发布）：p.4–6 说明范围、岗位与等级，p.8、p.11 涉及图像 2D 拉框和质检要求。它属于职业技能等级标准，不等同于人社部国家职业技能标准；正式提交须以团队持有版本和教师复核记录为准。公开副本：[PDF（华为云）](https://pvc-e7031f9b-6522-11e9-883f-fa163e9e2c22.obs.cn-north-1.myhuaweicloud.com/prod/image/2021-03-15/7ecb958ab9b44d52955b66fbef10e5ab.pdf)。
2. **S2：《人工智能训练师国家职业技能标准（2021 年版）》**（职业编码 4-04-05-05，人力资源和社会保障部、工业和信息化部制定，依据人社厅发〔2021〕81 号公布）：p.5 说明包含数据标注员工种，p.10、p.12 涉及视觉数据标注及准确性/完整性审核。正式提交须以团队持有版本和教师复核记录为准。
3. **S3：Microsoft COCO Dataset Data Format**（[官方格式页](https://cocodataset.org/dataset/format-data.htm)）：仅用于 `bbox=[x,y,width,height]`、`area`、`iscrowd` 等字段结构和坐标起点参考。COCO 格式本身不定义 `occluded`/`truncated` 属性，也不单独规定“不得越界”的平台校验；这两个属性及边界校验的名称、取值和是否必填必须以学校标注平台 schema 或经教师核验的实训手册为准。

> 来源核验：请填写 `AI数据标注实训智能体-场景来源核验模板.md`，并附实际课程/平台版本、教师复核记录和可追溯条款。当前页面中的规则是可运行的候选规则；在教师核验前，不宣称其已严格对应学校平台字段或某一标准的唯一条款。

S1–S3 的本地文件哈希和页码定位见 `AI数据标注实训智能体-来源文件核验清单.md`；规则与输出的逐条对应见 `AI数据标注实训智能体-来源规则输出映射.md`；《AI数据标注实训智能体-知识来源核验审计.md》是只读的来源边界审阅，不能替代教师复核、实际持有版本或授权确认。

## 自动化验收

在前端目录执行 `npm run smoke:ai-annotation-agent`，脚本会检查主/兼容入口、流程图示和框选示意、遮挡步骤、规则追踪元数据、来源前缀、多意图澄清、模糊追问、同类实例步骤、反馈确认、A/B/C 连续录入、保存、CSV 导出和关闭重开等路径。该脚本是技术回归检查，不替代真实用户试用。

## MVP 入口

启动学生端后访问 `/annotation-agent`（兼容旧地址 `/ai-annotation-agent`）。快捷问题可验证遮挡、截断和同类实例规则；反馈窗口要求先选择“真实用户试用”或“AI 模拟（内部演示）”，提供 A/B/C 匿名身份、实用性/易用性/准确性 1-5 分评价，并要求匿名确认后才可保存。可连续录入三位参与者并按记录类型导出 CSV；真实用户类型生成 `AI数据标注真实用户反馈.csv`，模拟记录生成带“AI模拟”字样的文件名。

页面顶部、场景提示和每条助手回答均设置明显的“AI生成内容 · 教学辅助”标识，并提示提交前由教师核验；该标识用于区分系统生成建议与真人反馈、教师结论或正式平台规则。

## 真实试用

邀请 2 名人工智能专业学生和 1 名计算机视觉/数据标注教师完成任务。页面反馈只记录真实填写内容；导出 CSV 后与匿名访谈记录或视频一起提交。开发者自测不能替代真实用户证据。

## 提交前人工核验与合规

正式提交前还需归档：真实场景来源记录、教师标准/平台字段复核记录、与 CSV 对应的匿名真人反馈及授权说明；由负责人和指导教师填写 `06-补充材料/AI数据标注实训智能体-外部证据人工核验声明模板.md` 的实际核验结果，并由负责人签署 `05-安全与合规/AI数据标注实训智能体-安全合规承诺模板.md`（按主办方要求提交签署版）。模板和自动化审计只能提示缺口，不能代替真人签名、身份核验或专业判断。
