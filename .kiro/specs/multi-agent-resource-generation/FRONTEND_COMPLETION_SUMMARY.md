## 已知问题

### 需要后端支持
1. **学生列表**: 当前使用模拟数据,需要从后端 API 获取
2. **课程列表**: 当前使用模拟数据,需要从后端 API 获取
3. **知识点列表**: 需要根据课程 ID 动态加载
4. **用户 ID**: 收藏功能需要当前登录用户的 ID

### 需要配置
1. **API 基础路径**: 需要在 `@/utils/request.js` 中配置正确的后端地址
2. **WebSocket**: 如果需要实时推送,需要配置 WebSocket 连接

### 优化建议
1. **虚拟滚动**: 当资源数量很大时,建议实现虚拟滚动
2. **图片懒加载**: 优化图片加载性能
3. **缓存策略**: 实现资源列表缓存,减少 API 调用
